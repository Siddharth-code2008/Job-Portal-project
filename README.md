
# REACT JOB PORTAL PROJECT
** HireHub – Job Portal**

HireHub is a job portal web application built using React and Tailwind CSS. It aims to help users explore job opportunities through a clean, responsive, and user-friendly interface.

**🛠️ Technologies Used**

- React.js
- JavaScript
- Tailwind CSS
- Vite

** ✅ Completed **

- Navbar UI
- Job listing section
- Reusable job card components
- Job details page
- Filter functionality
- React Router for page navigation

** 🚀 Upcoming Features **

- Savedjob page
- Application page
- login page
- local storage
- Responsive design 

** 🎯 Project Goal **

The goal of this project is to practice React development, component reusability, props, and responsive UI design while building a practical job portal application.
